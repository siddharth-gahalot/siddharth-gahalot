### 01. Trendverse

**A unified view of what's trending across the internet.**

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/siddharth-gahalot)

`Python` `Async Programming` `Google Cloud Firestore` `Cloud Scheduler`

**Engineering focus:** API integration · Asynchronous I/O · Data aggregation · Cloud-backed storage

### 02. Multiple Disease Prediction

**Machine learning models for exploring health-related prediction tasks.**

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/siddharth-gahalot)

`Python` `Scikit-learn` `Logistic Regression` `SVM` `StandardScaler`

- Developed predictive models for diabetes and heart disease datasets.
- Reported model accuracies of 90% for diabetes and 85% for heart disease in the original project evaluation.
- Applied feature scaling, stratified train-test splitting, and exploratory correlation analysis.
- Visualized data relationships to support model evaluation and interpretation.

**Engineering focus:** Data preprocessing · Classification · Model evaluation · Feature analysis

*Note: These are experimental prediction models, not clinically validated diagnostic systems.*

### 03. AirBrush

**A real-time, gesture-controlled digital drawing application.**

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/siddharth-gahalot/AirBrush)

`Python` `OpenCV` `MediaPipe` `Computer Vision`

- Developed a hands-free drawing interface using real-time hand-gesture tracking.
- Used deque-based coordinate management to maintain drawing trajectories and support smooth rendering.
- Implemented gesture-based controls for selecting colors and clearing the canvas.
- Targeted real-time interaction at approximately 30 FPS, with tracking accuracy reported at around 70% in the original project description.

**Engineering focus:** Computer vision · Gesture recognition · Real-time processing · Interactive systems
